# Keep the confirmed transaction as the receipt import record

A receipt image can contain personal details beyond the purchase that MeowPaid tracks. MeowPaid uses the upload during the recognition flow and discards it, so the image is unavailable for later review. The user confirms the receipt draft before MeowPaid saves the transaction as the lasting purchase record.

The original receipt photo stays in the browser. The user selects the area to share and explicitly starts recognition, which sends the cropped receipt image to the server and OpenRouter.
